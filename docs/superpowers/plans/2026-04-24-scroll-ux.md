# Scroll UX Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix amux scroll wheel behavior so it matches industry-standard terminal emulators — wheel → arrow keys in alt-screen apps without mouse reporting, tmux copy-mode on main screen, slower/configurable speed, and a read-only vertical scrollbar.

**Architecture:** `VTerminal` tracks `isAltScreen` + `mouseMode` via libvterm's `settermprop` callback. `KeyInput.scrollBytes` branches on that state to emit either cursor-key sequences or SGR mouse events. `Config.swift` enables tmux `mouse on` and installs alt-screen-aware `WheelUpPane`/`WheelDownPane` bindings so main-screen wheel enters copy-mode. `TerminalView` renders an `NSScroller` (`.overlay` style) sized from tmux `#{history_size}`/`#{scroll_position}`, hidden in alt-screen.

**Tech Stack:** Swift 5.9+, AppKit (`NSScroller`), `libvterm` via the `CVterm` module, tmux 3.x.

**Spec:** `docs/superpowers/specs/2026-04-24-scroll-ux-design.md`

```swift
private func onSetTermProp(_ prop: VTermProp, _ val: UnsafeMutablePointer<VTermValue>?, _ user: UnsafeMutableRawPointer?) -> Int32 {
    guard let val = val else { return 1 }
    let terminal = Unmanaged<VTerminal>.fromOpaque(user!).takeUnretainedValue()
```

```swift
/// Encode a scroll-wheel event for tmux / the pane app.
///
/// In alt-screen apps without mouse reporting, emit cursor-key sequences
/// (ESC [ A / ESC [ B) — matches xterm alternateScroll, Alacritty, WezTerm,
/// VTE, iTerm2. Otherwise emit SGR mouse events for tmux's `mouse on`
/// binding to interpret (copy-mode on main screen, pass-through in
/// alt-screen + mouse mode).
///
/// Speed: 1 line per wheel tick on imprecise wheel events (macOS
/// pre-multiplies), shift multiplies by 5, precise trackpad uses
/// deltaY / cellHeight. Hard cap of 10 lines per event guards against
/// runaway touchpad deltas.
static func scrollBytes(
    deltaY: CGFloat,
    col: Int, row: Int,
    cellHeight: CGFloat,
    precise: Bool,
    shiftHeld: Bool,
    isAltScreen: Bool,
    mouseMode: VTerminal.MouseMode,
    visibleRows: Int
) -> [Data] {
    let shiftMult = shiftHeld ? 5 : 1
    let baseLines: Int
    if precise {
        baseLines = max(1, Int(abs(deltaY) / cellHeight))
    } else {
        baseLines = 1
    }
    let lines = min(10, baseLines * shiftMult)

    let up = deltaY > 0

    // Alt-screen + no app mouse mode → cursor keys (solved industry pattern)
    if isAltScreen && mouseMode == .none {
        let seq = up ? "\u{1B}[A" : "\u{1B}[B"
        let data = seq.data(using: .utf8)!
        return Array(repeating: data, count: lines)
    }

    // Else: SGR mouse. tmux with `mouse on` + WheelUpPane/WheelDownPane
    // bindings decides: copy-mode in main screen, pass-through in alt.
    let button = up ? 64 : 65
    let sgrCol = col + 1
    let sgrRow = row + 1
    let seq = "\u{1B}[<\(button);\(sgrCol);\(sgrRow)M"
    let data = seq.data(using: .utf8)!
    return Array(repeating: data, count: lines)
}
```

```swift
// Main screen → enter copy-mode and scroll pane history.
// Alt screen → pass wheel through to the pane app (which amux has already
// translated to arrow keys when the app isn't consuming mouse events).

// Root-table bindings so they fire on raw wheel events (no prefix required).
// Use tmux command-block syntax `{ ... }` so multi-statement branches
// (e.g. `select-pane -t= ; copy-mode -eu`) parse as a single command.
// Quoting as one argv string avoids tmux argv-parser ambiguity around `;`.
```

- Else if `alternate_on=1` (alt-screen app) → `send-keys -M` so the SGR event flows to the pane app.
- Else (main screen, not in copy-mode) → enter copy-mode at current position and scroll.

Add a method on `TerminalView`:

```swift
private func queryTmuxScrollState() -> (historySize: Int, scrollPosition: Int?)? {
    // Targets the active pane of the default client (no -t flag).
    // TerminalView hosts the entire tmux client; tmux multiplexes panes
    // internally and tracks the active one. scrollPosition is empty when
    // not in copy-mode.
    let out = Tmux.runRaw([
        "display-message", "-p",
        "#{history_size} #{?pane_in_mode,#{scroll_position},}"
    ]).trimmingCharacters(in: .whitespacesAndNewlines)
    if out.isEmpty { return nil }
    let parts = out.split(separator: " ", maxSplits: 1, omittingEmptySubsequences: false)
    guard let hist = Int(parts[0]) else { return nil }
    let posStr = parts.count > 1 ? String(parts[1]).trimmingCharacters(in: .whitespaces) : ""
    let pos: Int? = posStr.isEmpty ? nil : Int(posStr)
    return (hist, pos)
}
```

No pane-id tracking required — `display-message -p` defaults to the current client's active pane, which is exactly the pane the user is viewing.

- [ ] **Step 2: Update the scroller on every query**

Add a method:

```swift
private func refreshScrollerState() {
    guard !terminal.isAltScreen else {
        scroller.isHidden = true
        return
    }
    guard let state = queryTmuxScrollState() else {
        scroller.isHidden = false
        scroller.knobProportion = 1.0
        scroller.doubleValue = 1.0
        return
    }
    let visible = CGFloat(terminal.rows)
    let total = CGFloat(state.historySize) + visible
    scroller.isHidden = false
    scroller.knobProportion = max(0.02, visible / max(visible, total))
    if let pos = state.scrollPosition, state.historySize > 0 {
        // scroll_position counts lines above the viewport; 0 = at bottom.
        scroller.doubleValue = 1.0 - (Double(pos) / Double(state.historySize))
    } else {
        scroller.doubleValue = 1.0
    }
}
```
